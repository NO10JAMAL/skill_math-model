# 论文写作规范

## 一、格式与一致性规范

- 术语和符号严格服从 `术语表格.md`。
- 每段围绕一个明确论点，先给事实或推理，再解释其含义。
- 数值、单位、公式、图号、表号和引用前后一致。
- 不使用”专家认为””效果显著”等无来源表述。
- 不用宣传性语言代替证据；创新点必须对应具体方法、实现和验证。
- 不虚构数据、实验、文献或官方要求。
- 两个模型得到相近结论时，如有比较价值，可如实保留并解释。
- 中文或英文表达服从目标竞赛和用户要求。

## 二、评阅人抓分方法论

数学建模竞赛评阅遵循”假设的合理性、建模的创造性、结果的正确性、表述的清晰性”四项基本原则。通用分项权重约为——模型假设合理性约 20% / 建模创造性约 25% / 结果表述清晰性约 25% / 论文格式规范性约 15% / 参考文献约 15%。**摘要与结果表述合计权重最高（约 50%+）**；评阅人常先花几十秒筛摘要与关键图表，再决定是否细读，抓分必须从摘要和结果入手。以下方法覆盖 CUMCM / MCM-ICM / APMCM 等各类竞赛，具体篇幅与结构始终以当届官方规则为准。

### 1. 摘要四段式 + 埋定量结果

- 严格四段式：**问题与挑战 → 方法 → 关键结果 → 验证与创新**。
- **关键结果必须带具体数值**（如”得到最优配比 (0.42, 0.31, 0.27)，误差 1.8%，优于基线 23%”），杜绝”效果良好/得到了较好的结果”等空泛表述。
- 摘要最后写，基于已定稿正文；摘要与正文必须完全一致（摘要说用 LSTM、正文却是 BP，会被质疑诚信）。
- 篇幅控制：CUMCM 600-900 字 / MCM 约 1 页，具体以当届官方为准；不放公式图表。
- 关键词至少含 2 个具体方法 + 2 个题目领域词（如”NSGA-II””碳足迹”），避免只有”数学建模””优化”等空泛词。

### 2. 结论段”一图一数一句”

每个结论紧跟：一张图 + 一个具体数值 + 一句话解释。例：”得到 X=12.3，意味着每天最多调度 12 辆车，与现实 10-15 辆一致。”避免只报数字不解读。

### 3. 评阅人快速抓分路径

评阅人按 摘要 → 问题重述 → 模型建立 → 结果图 → 结论 抓分，每个部分都有独立得分点：

| 部分 | 抓分点 |
|---|---|
| 摘要 | 问题、方法、关键数值、验证、创新一句话讲清 |
| 问题重述 | 用自己的语言重述，明确核心任务、输入、约束和输出 |
| 模型建立 | 每个子问题结论有对应公式、参数、输入输出、验证方式 |
| 结果图 | 每子问题至少 1 流程图 + 1 结果图，图表编号、标题、正文引用齐全 |
| 结论 | 直接回答题目要求，关键数值突出 |

### 4. 反模式对照自查

写作时对照以下高频扣分反模式自查：

**摘要类（扣分最重）**
- 摘要无定量结果、结构混乱、与正文不符、关键词空泛、篇幅失控、塞公式图表。

**结果分析类**
- 只报数字不解读；纯表格无图；图表配色丑；图表无编号标题；灵敏度只改代入值不重新求解；灵敏度参数乱选。

**模型选型类**
- 直接套课本模型无针对性处理；模型与问题不匹配；候选模型同族假对比；选型理由薄弱；选 NP-hard 不验证可行性。

**假设符号类**
- 假设无支撑、假设过多/过少；符号重复定义、无单位、未定义先出现；量纲不一致。

### 5. 创新性信号

“建模创造性”权重约 25%，是冲奖关键。创新必须对应具体方法、实现和验证，并按以下信号呈现：

- **自创算法**：针对赛题特殊结构设计的算法，说明算法动机。
- **跨领域模型融合**：把 A 领域方法用于 B 领域，论证合理性而非简单堆砌。
- **经典方法针对性改进**：明确改在哪里、为何要改，附改进前后对比验证。
- **新颖数学抽象**：对问题的数学抽象简化得当且保留本质。
- **多方法协同**：不同子问题用不同方法并论证衔接逻辑。

任何创新都必须伴随**对比验证**（改进前后对比、不同方法对比、灵敏度分析），证明有效而非自说自话。

## 三、学术中立性与去 AI 风格规范（Anti-AI Guidelines）

评阅专家对大语言模型（LLM）润色带来的“大模型腔调”极其敏感，AIGC 检测系统（如知网、Turnitin、CopyLeaks）亦高度关注高频套话、极端词与句式平滑度。论文必须严格遵循学术中立性与克制原则：

### 1. 禁用戏剧化与情绪化套话（红线禁词库）

论文中**严禁使用**任何文学化隐喻、惊叹词或非学术性赞美词，必须替换为客观、克制的数理统计表达：

| 严禁使用的 AI 套话 | 学术规范推荐表达 | 禁用原因 |
|---|---|---|
| **令人极大震惊 / 令人大跌眼镜** | 实测结果显示 / 统计表明 / 检出率退化为 0 | 评阅论文不是新闻报道，禁止主观惊叹 |
| **发人深省 / 极具震撼力** | 揭示出以下规律 / 具有明确的运筹决策启示 | 避免空洞的心得体会式修辞 |
| **滑向...不可逆高危深渊** | 面临中晚期临床干预的高风险 | 严禁文学化隐喻，使用专业医学术语 |
| **压倒性优势 / 无可辩驳** | 似然比检验具有极强统计显著性（p < 0.001） | 用置信度与 p 值说话，不用宣传用语 |
| **展现出卓越的 / 无与伦比的** | 表现出优良的抗噪性能与工程鲁棒性 | 禁止主观夸耀，用具体指标证明 |
| **毁灭性失效 / 灾难性** | 规则无法适应高背景噪声 / 模型失效 | 客观陈述机理，不用灾难性形容词 |
| **必要且充分的建模哲学** | 严格依据赛题背景与生物物理机理设立假设 | 避免拔高到哲学层面，保持数理务实 |

### 2. 长短句交错与自然节奏（提升突发度 Burstiness）

- **避免匀速长句**：禁止整段文字全部由 40~60 字的复合长句组成。在长句阐述机理后，适时穿插 10~20 字的凝练论断句（如“检验结果拒绝原假设。”、“参数未达显著水平。”、“各组时点表现出高稳定性。”）。
- **打破机械对称**：不要通篇机械使用对仗工整的“第一，...；第二，...；第三，...”。适当通过逻辑关联词（“然而”、“进一步分析表明”、“由表可见”）自然流转段落。

### 3. 元数据与生成标记脱敏

- 保存 Word 时必须确保文档属性（`core_properties`）中无 `python-docx`、`generated by` 等脚本生成签名，保持文档属性干净纯洁。
- 交付前必须通过 `ai_style_audit.py` 自动化检测，确保零警告交付。

## 四、标杆国一论文版式架构与视觉规范（以 2025 C132 国一论文为范本）

为使生成的论文达到全国一等奖标杆水平，排版与结构必须对齐 2025 年高教社杯全国大学生数学建模竞赛国一优秀论文（如 C132 范本）：

### 1. 论文总体架构：“大十段式”结构
除首页摘要及文末附录外，正文一级标题采用大写中文编号，且各章之间**自然流转顺延，不强制分页**（除非排版避头尾要求）：
- `一、  问题重述`
- `二、  问题分析`（独立大模块，内含总体思路与求解路线流程图）
- `三、  模型假设`
- `四、  符号说明`（紧跟三线表形式的符号表）
- `五、  数据预处理`（或问题机理分析/特征工程）
- `六、  问题一的模型建立与求解`
- `七、  问题二的模型建立与求解`
- `八、  问题三的模型建立与求解`
- `九、  问题四的模型建立与求解`（依赛题问数自适应拓展）
- `十、  模型的评价、改进与推广`
- `参考文献`
- `附录 A  文件列表`（三线表罗列脚本文件名、环境及功能）
- `附录 B  代码`（带题注与行号的等宽代码清单）

### 2. 首页与摘要规范
- **论文题目**：居中，三号黑体加粗（16pt），段前段后各 12pt。
- **摘要标题**：`摘  要`（两字居中，字间空两格，小三黑体加粗 15pt）。
- **问题导引加粗**：摘要正文中针对各问的段落首句，必须使用加粗导引（如“**针对问题一，**”、“**针对问题二，**”），使评阅专家在 30 秒内迅速定位各问模型、核心解法与关键定量结果。
- **关键词规范**：小四黑体加粗`关键词：`，词与词之间**必须使用两个半角空格分隔，严禁使用分号**（例如：`关键词： 随机森林  多目标规划  NSGA-II  灵敏度分析`）。
- **强制分页**：摘要页结束必须强制插入分页符，正文从第 2 页起始。

### 3. 标题层级与编号格式
- **一级标题**：居中，三号黑体加粗（16pt），格式为`一、  标题`（序号后加两个空格），`keep_with_next=True`，段前 12pt、段后 6pt。
- **二级标题**：顶格左对齐，小三黑体加粗（14pt），格式为`1.1  标题`（序号后加两个空格），`keep_with_next=True`，段前 6pt、段后 3pt。
- **三级标题**：顶格左对齐，四号或小四黑体加粗（12pt），格式为`1.1.1  标题`（序号后加两个空格），`keep_with_next=True`。
- **步骤段落小标题**：顶格左对齐，小四黑体加粗（12pt），如`(1) 缺失值剔除与插值` 或 `Step 1: 策略矩阵构建`。

### 4. 公式、图、表规范
- **公式居中与编号右对齐**：使用 `equation_numbered()`，利用 Word 双制表位（居中制表位 + 页面右边界制表位），使原生 OMML 公式严格居中，公式编号如 `(1)` 严格紧贴右侧页边距，严禁使用表格包裹公式（避免破坏表格计数与题注校验）。
- **表格与题注**：
  - 题注置于表格**上方居中**，格式为`表 1  符号说明表`（两个空格），五号黑体加粗（10.5pt），`keep_with_next=True`，段前 6pt、段后 2pt。
  - 表格采用紧凑三线表，表格内容字号为五号（10.5pt），行距 1.15 倍，段前段后 2pt。
- **图片与题注**：
  - 题注置于图片**下方居中**，格式为`图 1  整体建模与求解流程图`（两个空格），五号宋体（10.5pt），段前 2pt、段后 6pt。
- **图表正文引用**：正文中凡出现数据或图表，必须使用形如“如表 1 所示”、“见图 1”进行双向呼应。

### 5. 附录呈现规范
- 附录独立分页，使用小二/三号黑体加粗居中标题（如`附录 A  文件列表`、`附录 B  代码`）。
- **附录 A 文件列表**：采用三线表呈现，列包含“文件名称”、“所属语言/软件”、“功能简要说明”。
- **附录 B 核心代码**：使用 `code_listing()` 呈现，采用 Consolas 8.5pt 等宽字体，单倍行距，每段代码附带题注（如`代码清单 B.1: 数据清洗主程序`）并保留清晰的注释。
